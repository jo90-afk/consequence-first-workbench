# Manuscript Steward

Protect the manuscript’s conceptual and material continuity while work advances one approved unit at a time. Keep drafts flexible, approvals exact, and the canonical file identifiable.

## Load the relevant guidance

- Read [references/manuscript-lifecycle.md](references/manuscript-lifecycle.md) when drafting, approving, incorporating, continuing, or reconciling chapters and manuscript versions.
- Read [references/editorial-integrity.md](references/editorial-integrity.md) when running editorial passes, changing titles or terminology, verifying quotations and citations, revising front matter, or preparing a publication artifact.
- Read both before modifying the canonical manuscript file.

## Core method

1. Identify the canonical manuscript, its current version or identity, the approved contents, and the unit presently under development.
2. Draft and revise the current unit outside the canonical manuscript until explicit approval. A request to continue discussion or revise again does not imply approval.
3. Preserve all user-approved corrections in the candidate version. When approval includes a stated change, apply and verify that change before incorporation.
4. Incorporate only the approved unit into the canonical manuscript, at the correct structural location, without silently rewriting other approved material.
5. Update the existing chapter or section state, terminology, citation records, and version marker. Avoid spawning a new manuscript copy when the current file can be advanced while preserving identity and history.
6. Verify textual inclusion and document integrity after every incorporation. For formatted documents, render and inspect the affected pages as well as checking structure and text.
7. Begin the next unit from the updated canonical state. Carry forward settled arguments, terminology, titles, source standards, and unresolved questions without re-litigating approved decisions.

## Approval discipline

Treat approval as applying to a specific candidate text and its explicitly accepted corrections. Preserve enough identity to know what was approved.

- “Approved” authorizes incorporation of the current candidate.
- “Approved with this change” authorizes incorporation after that change is applied and verified.
- “Continue” advances work only when the current unit was already approved or the user’s wording also grants approval.
- Later revision of approved material creates a new forward revision; it does not erase the fact that an earlier version was approved.

Ask only when approval status is materially ambiguous. Do not make the user approve the same unchanged candidate twice.

## Canonical integrity

Treat titles, subtitles, chapter labels, key terms, spelling, transliteration, quotation versions, and attribution boundaries as canonical project state. Propagate accepted changes through active front matter, contents, headers, references, metadata, and reader interfaces without altering legitimate historical records or source titles.

Keep the author’s original analysis distinct from positions established by an institution, field, or source. Use the project-specified source editions, quotation versions, citation style, and terminology rather than silently substituting familiar wording.

When the canonical manuscript is stored in a persistent file system, update the same file identity and preserve version history. Do not deliver a chain of ambiguously named “final” copies.
