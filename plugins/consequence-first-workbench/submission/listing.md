# Marketplace listing draft

## Name

Consequence-First Workbench

## Short description

Trace consequences, preserve truth, and ship coherent work.

## Long description

Consequence-First Workbench is an integrated set of eleven skills for work in which decisions, evidence, state, prose, interfaces, and implementation depend on one another. It helps turn rough ideas into build-ready projects, map arguments by conceptual function, propagate accepted changes, protect canonical artifacts, translate models into interfaces, deliver software iteratively, steward long-form manuscripts, and coordinate bounded work with explicit proof and acceptance.

The bundle is author-neutral and domain-neutral. It adds no MCP server or app and requires no plugin-specific account.

## Category

Productivity

## Suggested prompts

1. Trace this decision through every material consequence before proposing the design.
2. Turn this rough project idea into build-ready state and define the next bounded work.
3. Audit this argument, verify its evidence, and translate the result into an interface.
